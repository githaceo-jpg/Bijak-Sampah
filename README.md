# Bijak Sampah — Website Edukasi SDGs

Website edukasi pengelolaan sampah rumah tangga dengan fokus SDG 11 (Kota dan Permukiman Berkelanjutan) serta SDG 12 (Konsumsi dan Produksi yang Bertanggung Jawab).

## Halaman
- `index.html` — Beranda
- `edukasi.html` — Jenis sampah: organik, anorganik, B3, residu
- `panduan.html` — Panduan 3R dan kebiasaan rumah tangga
- `artikel.html` — Artikel dan inspirasi
- `tentang.html` — Tim dan referensi

## Teknologi
- HTML5 semantik
- CSS3 eksternal, Grid, Flexbox, media queries
- Tanpa framework CSS dan tanpa backend/database

## Menjalankan
1. Ekstrak folder ZIP.
2. Buka folder `Bijak_Sampah_Professional` di VS Code.
3. Buka `index.html` melalui Live Server, atau klik dua kali file tersebut.
4. Internet diperlukan untuk memuat Google Fonts dan foto dari Unsplash.

## Sebelum dikumpulkan
- Ganti nama, NIM, dan pembagian tugas di `tentang.html` sesuai anggota kelompok.
- Periksa kembali seluruh konten dan tautan referensi.
- Uji responsif di lebar 1440 px, 768 px, dan 375 px.
- Publikasikan ke GitHub Pages dan masukkan URL repository serta URL website ke laporan.
